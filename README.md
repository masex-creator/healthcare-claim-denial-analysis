# Healthcare Claim Denial Analysis

## Business Problem

Healthcare organizations lose significant revenue and operational time due to denied insurance claims. This project analyzes the most common denial reasons across multiple insurance types to identify patterns and areas for process improvement.

---

## Tools Used

- SQL (BigQuery)
- Tableau Public
- CSV Dataset

## SQL Analysis

The SQL analysis focused on identifying the most common denial reasons across different insurance types by filtering denied claims and grouping denial categories.

Key SQL techniques used:
- WHERE filtering
- GROUP BY aggregation
- COUNT aggregation
- ORDER BY sorting

---

## Key Insights

- Medicaid claims showed the highest rate of patient eligibility denials.
- Medicare claims frequently failed due to authorization-related issues.
- Commercial claims were commonly denied for medical necessity and billing errors.
- Missing documentation appeared consistently across all insurance categories.
- Authorization-related denials were a major issue across Medicare, Medicaid, and Self-Pay claims.

---

## Business Recommendations

- Strengthen patient eligibility verification before claim submission.
- Improve authorization workflows for Medicare and Medicaid patients.
- Implement billing validation checks to reduce coding and billing errors.
- Standardize documentation review procedures before submission.
- Create automated alerts for missing authorization requirements.
